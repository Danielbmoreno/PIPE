# Documentación PIPE (Pack corporativo)

Este directorio contiene la documentación generada para el sistema **PIPE**.

## Archivos
- `MANUAL_USUARIO_PIPE.md` — Guía para usuarios no técnicos.
- `MANUAL_TECNICO_PIPE.md` — Arquitectura, stack, endpoints, modelos, seguridad, estabilidad.
- `DIAGRAMAS_PIPE.md` — Diagramas Mermaid.js (arquitectura, flujo de datos, módulos).
- `SEGURIDAD_Y_ESTABILIDAD_PIPE.md` — Riesgos actuales y recomendaciones hardening.
- `GUIA_DESPLIEGUE_PIPE.md` — Guía de despliegue local/producción y variables de entorno.
- `DOCUMENTO_EJECUTIVO_PIPE.md` — Resumen ejecutivo para empresa y roadmap.
